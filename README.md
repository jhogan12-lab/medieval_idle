# Eras - Historical Progression Idle Game

Still workshopping the name, but Eras is a work in progress idle game where you progress throughout different eras of world history. From the beginnings of civilazations in Africa and the Middle East, to the Roman Golden Age, to the modern era, there will be plenty of tapping and gameplay to enjoy.

Disclaimer: this is a complete work in progress and is used to showcase my work for future potential employers.
